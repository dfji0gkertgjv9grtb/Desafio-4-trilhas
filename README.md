# Acesso à Educação Básica no Brasil

Este projeto visa apresentar, de forma visual e interativa, o panorama do acesso à educação básica no Brasil.

## Estrutura

- **index.html**: página inicial com visão geral do projeto.
- **dashboard.html**: exibição dos dados por estado.
- **css/style.css**: estilos do projeto.
- **js/main.js** e **js/dashboard.js**: scripts JavaScript.

## Fonte de Dados

- IBGE (API de estados)
- Simulação de acesso à educação
